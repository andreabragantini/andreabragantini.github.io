I built this project mainly to learn Microsoft web development tools in a practical way, not just from tutorials.

The idea was simple: create a small time management app where I can add activities, organize them by type, and track what I’m doing during the day. Nothing fancy, just something useful enough to feel real.

This project helped me understand how the ASP.NET Core MVC workflow fits together, from backend logic to pages and data. I also got more confident with the everyday developer flow: run, test, break things, fix them, repeat.

It’s a beginner-friendly project, but for me it was an important step from “studying code” to actually building something end to end.
